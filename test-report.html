本次测试修复的问题

后端工单 DELETE 端点缺失
问题：WorkOrderController 完全没有 @DeleteMapping 端点，DELETE 请求返回 500 服务器内部错误。
修复：在 WorkOrderService 接口、WorkOrderServiceImpl、WorkOrderController 三层添加 delete(Long id) 方法，使用 MyBatis-Plus 逻辑删除（@TableLogic）。
后端客户/经销商/运维人员 DELETE 端点缺失
问题：CustomerController、DealerController、WorkerController 均无 @DeleteMapping 端点。
修复：三个 Controller + Service + ServiceImpl 均添加 delete(Long id) 方法，包含存在性校验和逻辑删除。
后端账户更新密码必填校验错误
问题：AccountCreateDTO 的 password 字段有 @NotBlank 注解，导致 PUT 更新账户时密码必填，返回 500。
修复：新建 AccountUpdateDTO（无 @NotBlank），更新接口改用此 DTO。
配置Long → String 序列化未生效
问题：JacksonConfig 注释写了"Long → String"但实际未实现。雪花算法 ID（19位）超过 JS 安全整数范围，导致前端收到的 ID 精度丢失。
修复：添加 SimpleModule + ToStringSerializer，所有 Long 字段序列化为 String。修改后需重新 mvn install + Docker 重建。
前端工单列表页缺少删除按钮
问题：workOrder/list.vue 操作列只有"查看详情"和"派单"，无删除功能。
修复：api/workOrder.ts 添加 deleteWorkOrder 函数，list.vue 添加 el-popconfirm 删除按钮和 handleDelete 方法。
前端套餐列表页缺少删除按钮
问题：package/list.vue 操作列只有"编辑"、"上架"、"下架"，无删除功能。
修复：api/package.ts 添加 deletePackage 函数，list.vue 添加 el-popconfirm 删除按钮和 handleDelete 方法。
