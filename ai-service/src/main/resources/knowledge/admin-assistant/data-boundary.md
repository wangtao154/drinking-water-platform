# AI 助手第三方数据边界

## 可发送给第三方生成模型的内容

1. 经过脱敏后的管理员提问。
2. 本目录内已发布、经权限过滤的静态操作知识片段。
3. 固定只读数据工具返回的已授权汇总事实，例如设备在线状态、统计时间范围、订单数、金额、取水量、告警数、工单数和设备遥测聚合指标。
4. 模型路由阶段仅可见脱敏后的提问和固定工具名称、参数结构；看不到内部接口地址、内部令牌或工具原始响应。

## 禁止发送的内容

不得向第三方模型发送或要求其恢复以下内容：密码、支付密钥、应用密钥、证书、访问令牌、内部接口地址、完整手机号、身份证号码、完整住址、邮箱完整前缀、OpenID、UnionID、银行卡号、完整微信交易号、原始审计日志、原始图片和附件。

平台在模型调用前会对问题、知识片段和数据摘要统一执行脱敏。出现疑似敏感字段时，模型只能看到“[已脱敏]”或“[已脱敏编号]”。

## 数据工具约束

1. 数据工具由平台代码固定注册，模型不能传入任意 URL、SQL、文件路径或内部令牌。
2. 所有工具均为只读查询；模型不能执行设备下发、支付、退款、派单、角色变更、阈值变更或删除操作。
3. 数据工具仅在当前后台账户拥有相应权限时执行，未授权、无数据或异常状态必须如实告知。

## 审计与维护

AI 审计日志只保留调用账户、时间、模型、数据工具、结果状态以及问题和回答的脱敏摘要与摘要指纹，不保存完整提问和完整回答。新增知识文档或数据工具时，必须先确认字段白名单和脱敏规则，再允许其进入第三方模型上下文。
