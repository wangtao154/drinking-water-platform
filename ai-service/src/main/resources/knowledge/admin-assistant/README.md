# 管理后台 AI 助手知识库

## 作用

本目录是管理后台 AI 助手第一期的受控操作知识来源。知识库用于回答“如何操作”“状态代表什么”“应查看哪个页面”等问题，不作为执行写操作、支付、退款或设备控制的依据。

## 文件规范

每篇知识文档必须包含以下元数据：

```yaml
---
id: 唯一英文标识
title: 面向管理员的中文标题
scope: 适用的后台模块
permissions: [所需权限编码]
sources: [已验证的页面、接口或工作记录]
updatedAt: YYYY-MM-DD
---
```

正文使用明确的操作步骤、状态说明、限制和风险提示。没有来源验证的内容不得写入“确定结论”。

## 检索规则

1. 仅检索本目录的 `.md` 文件，禁止从用户输入、数据库字段、任意 URL 或上传文件动态加载提示词。
2. 检索结果必须返回知识标题、文件标识和更新时间，供前端展示引用来源。
3. 用户无对应 `permissions` 时，不向模型提供该文档正文；助手只提示“当前账号无权查看该模块”。
4. 回答与实际数据相关的问题时，知识库只提供流程，具体数值必须由受控只读数据工具查询后再提供给模型。

## 维护规则

1. 页面行为、状态机、接口权限或业务规则变更时，同一提交必须同步修改相应知识文档。
2. 每次更新需调整 `updatedAt`，并在文件末尾的“变更记录”追加简短说明。
3. 发现知识与线上行为不一致时，先停用或修正文档，不允许模型以过期说明指导操作。
4. 不得写入密钥、证书、Token、完整手机号、完整地址、OpenID、银行卡号或完整微信交易号。

## 当前覆盖范围

1. 设备与历史遥测。
2. 告警与阈值。
3. 工单流转。
4. 扫码订单与退款状态。
5. 报表中心与历史数据导出。
6. 角色、账户与审计。
