🔧 本次验证发现并修复的 3 个问题
  • 1. device-service 路由不匹配（@GetMapping("/") → @GetMapping）
    现象：GET /api/v1/devices 返回 500 NoResourceFoundException
    原因：Spring MVC 6 中 @GetMapping("/") 不匹配无尾斜杠 URL
    修复：DeviceController.java 中 @GetMapping("/") → @GetMapping，@PostMapping("/") → @PostMapping
    重新编译 + 重建 Docker 镜像 + 重新部署
    ✅ 修复后 API 返回 200，容器 healthy
  • 2. RabbitMQ 用户丢失（ACCESS_REFUSED）
    现象：device-service health 中 rabbit 组件 DOWN，报 ACCESS_REFUSED
    原因：RabbitMQ 容器重启后 users 列表为空（definitions.json users 数组为空）
    修复：docker exec rabbitmqctl add_user admin "RabbitMQ@2026" + set_user_tags administrator + set_permissions
    device-service 重启后 rabbit 组件恢复 UP
    ✅ 修复后 RabbitMQ 认证正常，所有服务健康
  • 3. finance-service 缺少 GET /invoices 列表端点
    现象：GET /api/v1/finance/invoices 返回 500 HttpRequestMethodNotSupportedException
    原因：FinanceController 只有 POST /invoices 和 GET /invoices/{invoiceNo}，缺少列表查询
    修复：FinanceService 新增 invoicePage 方法，FinanceController 新增 @GetMapping("/invoices")
    编译修复：PageResult.of() 需要 IPage 参数 → 改用 new PageResult<>(total, size, current, records)
    重新编译 + 重建 Docker 镜像 + 重新部署
    ✅ 修复后 API 返回 200，容器 healthy
